Sobre

Segunda a sexta, 08:00–18:00. Almoço de 1h30 → 8h30 por dia; pagando banco (almoço de 1h) → 9h00. Com só 2 marcações no dia, o almoço é descontado automaticamente. Sábado, domingo e feriado trabalhados contam inteiros como extra.

Saldo do dia = trabalhado − previsto + ajuste.

Horário menor que o anterior conta no dia seguinte (+1 dia).

Importar planilha antiga
O saldo anterior provavelmente já é o saldo desta planilha. Se mantiver os dois, as horas ficam duplicadas.
    Antes de importar, uma cópia dos dados atuais é guardada neste aparelho para você poder desfazer.
